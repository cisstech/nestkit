# Installation

## Prerequisites

- NestJS v10+ or v11+
- PostgreSQL database
- TypeORM installed and configured

## Install

```bash
yarn add @cisstech/nestjs-pg-pubsub pg
```

Or with npm:

```bash
npm install @cisstech/nestjs-pg-pubsub pg
```

`pg` is a peer dependency. Skip it if you already have it.
