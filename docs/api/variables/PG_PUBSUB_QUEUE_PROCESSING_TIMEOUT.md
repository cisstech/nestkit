# PG_PUBSUB_QUEUE_PROCESSING_TIMEOUT

`const`

Default processing timeout in milliseconds.
Messages stuck in 'processing' longer than this are considered orphaned.

```typescript
const PG_PUBSUB_QUEUE_PROCESSING_TIMEOUT: number
```
